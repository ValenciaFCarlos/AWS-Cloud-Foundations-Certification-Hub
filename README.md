# 📖 Overview

AWS Cloud Foundations & Certification Hub is a complete learning repository designed to help students, professionals and cloud enthusiasts develop a strong understanding of AWS Cloud Computing and prepare for the AWS Certified Cloud Practitioner (CLF-C02) certification.

This repository combines:

- 📚 Study guides
- ☁️ Cloud concepts
- 🔐 Security and compliance notes
- ⚙️ AWS services documentation
- 💰 Billing and pricing resources
- 🎯 Exam preparation material
- 🧠 Quick reference guides
- 🚀 Interactive AWS CLF-C02 Simulator

The objective is not only certification preparation, but also building a solid cloud foundation and architectural thinking.
